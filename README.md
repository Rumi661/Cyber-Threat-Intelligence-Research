# Cyber-Threat-Intelligence-Research

An independent cybersecurity portfolio project focused on emerging cyber threats, threat actor analysis and intelligence reporting.

## Project Objectives
- Conduct open-source intelligence research.
- Evaluate threat actors, tactics, techniques and procedures (TTPs).
- Assess potential organisational and sector-specific risks.
- Produce evidence-based, actionable intelligence reports.

## Project Status
Research in progress. Initial intelligence assessments and supporting documentation are planned for publication by 9 November 2026.
